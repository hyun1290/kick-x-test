# 남은 구현과 결정 사항

기준: 2026-10-03 KST. 2026-11-11 완료 목표. 화면과 BSD 기반은 준비됐지만 사용 가능한 거래 서비스가 되려면 계산·정산·영구 저장을 우선 완성해야 한다. 아래 기능의 자동 갱신은 이번 작업에 포함하지 않는다.

## 구현 우선순위와 완료 기준

| 순서 | 구현 | 완료 기준 |
| --- | --- | --- |
| 1 | 이번 전체 수집 코드를 운영 DB에서 실행, 데이터 품질 확인 | 5대 리그 현재 선수·일정·종료 경기 수/경고 확인, 재수집 중복 없음, 목록·상세 원본 일치 |
| 2 | Performance 전처리와 계산 엔진 | 출전 구간·자책골·카드 중복·클린시트·실점 귀속·0/결측 판정. 동일 입력/규칙 버전에서 동일 결과, 계산 근거 저장 |
| 3 | 초기 가치·경기별 가치 갱신·가격 이력 | 확정 공식/상하한/변동 제한 적용, 경기 재처리 중복 반영 없음, 경기 정정과 이후 가격 재계산·이력 보존 |
| 4 | 초기 포인트·지갑·원장·시스템 상대 구매/판매 | 최초 지급 1회, 요청 중복 키·동시 요청·잔액 부족·가격 변경 검증, 잔액·보유·원장 원자적 정산 |
| 5 | 자산·거래내역·스쿼드 저장 | 실제 잔액/평가액/손익 표시, 재로그인 유지, 미보유·중복·포지션·11명 초과 검증, 매각 시 스쿼드 처리 |
| 6 | 주간·월간 랭킹 | 기간 경계와 기준 자산 스냅샷, 분모/신규 회원/동률 규칙에 따른 재현 가능한 집계 |
| 7 | 구단/선수 커뮤니티 영구 저장 | 글·댓글·공감·신고 CRUD/RLS, 작성자/응원 구단 권한, 서버 입력 검증. 본인 거래 첨부는 선택 기능 |
| 8 | 관리자 운영과 AI 분석 | 신고 숨김/복구·처리 이력, 계산 재처리 권한. AI는 저장된 경기/가격 변화만 설명하고 기준 시점·근거를 보존 |
| 9 | 통합·운영 검증 | 실제 Google 재로그인/계정 격리, 수집→가치→거래→자산→랭킹, 실패 복구, 응답 속도, 배포 환경 점검 |
| 추후 승인 범위 | 자동 갱신 | 사용자가 진행을 요청한 뒤 스케줄·재시도·정정 재수집·모니터링 설계/구현 |

현재 `player_market_snapshots`, `price_history`, `player_analyses` 테이블은 표시/저장 기반이다. 계산 규칙·실행 버전·정정 의존성까지 완성된 엔진으로 보지 않는다. 지갑·거래·보유·스쿼드·커뮤니티 저장 테이블은 아직 없다.

## 구현 전에 결정할 정책

| 분야 | 미정 사항 |
| --- | --- |
| 포인트 | 초기 지급액, 정밀도/반올림, 추가 지급 조건 |
| Performance | 최신 명세 점수 기준안의 MF 태클/인터셉트 적용 단위, 미출전·부분 출전·결측·카드 중복·정정 처리, 포지션 기준 시점 |
| 가치 | 선수 초기 가치, Performance→변동률 공식, 평가 기준/기간, 하한·상한·경기당 변동 제한 |
| 거래 | 공통 판매 수수료율, 동일 선수 보유 수량/한도, 견적 유효 시간, 수수료 반올림 |
| 스쿼드 | 허용 포메이션, 다중 포지션, 매각/이적 처리, 빈 자리 허용 |
| 랭킹 | 주간/월간 수익률 분모, 현금 흐름 반영, 기간 시간대/경계, 신규 회원·동률 |
| 계정/커뮤니티 | 응원 구단 변경과 쓰기 권한, 탈퇴/보존, 숨김/복구 정책 |
| AI | 필수 기능을 무료 범위에서 실행할 방법, 실행 시점·캐시·근거 보존 |

화면의 2%·1,300,000P·Performance 100점 만점은 확정하지 않는다. 거래 수요로 가격을 직접 결정하는 예전 안은 제외됐다.

## 후속 기술 보완

- 원문 이름과 별도의 한글 표시명/별칭 매핑. 선수 ID로 식별하고 이름으로 합치지 않는다.
- 전체 시즌 반복 수집을 최근 경기/정정 대상 중심으로 줄이는 증분 수집. 현재는 수동 전체 갱신이다.
- 다량 적재 이후 실제 1초 화면/2초 검색·상세·거래/10초 AI 목표 측정. 테스트 통과가 운영 응답 시간 보장은 아니다.
- 현재 시즌에서 제외된 선수/구단의 검색 노출·거래 자격을 정책과 함께 정한다. 과거 기록과 관심 선수 참조는 보존한다.
- 전체 수집 경고 외에 필드별 통계 품질·사진 미제공 비율·경기 정정 비교 화면을 보강한다.
