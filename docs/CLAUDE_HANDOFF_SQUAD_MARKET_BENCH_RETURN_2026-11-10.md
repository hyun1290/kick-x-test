# 스쿼드 작은 선수 시장의 벤치 복귀

2026년 11월 10일 기준. 벤치 정책과 버튼에 대해서는 이 문서가 11월 9일 인계장보다 우선합니다.

## 현재 정책

- 주전은 최대 11명과 선택한 포메이션의 포지션별 정원을 지킵니다. 벤치를 포함한 보유는 11명을 넘을 수 있습니다.
- 벤치 평가액과 매각에는 현재 공통 시세를 반영합니다. 화면 명칭은 `벤치`, 가격 항목은 `현재 가치`입니다.
- 벤치 이동 후 7일(168시간) 안에 조건을 충족하면 무료로 주전 복귀할 수 있습니다. 복귀해도 보유 원가와 포인트는 유지합니다.
- 복귀에는 현재 소속·포지션·가격·빈 정원·경기 제한·기한·최신 스쿼드 수정 번호 검사가 적용됩니다.
- 복귀한 선수는 자동 매각 대상에서 제외합니다. 남아 있는 벤치는 기한 이후 기존 자동 작업에서 현재 시세와 2% 수수료로 매각합니다. 경기 제한 중이면 해제 후 처리합니다.
- 기존 벤치의 시작 시각과 기한을 반복 수집이나 포메이션 변경으로 연장하지 않습니다.

## 이번 화면 변경

`components/kickx/squad.tsx`의 오른쪽 작은 선수 시장에서도 본인이 벤치로 보유한 선수에게 `주전 복귀`와 `매각`을 함께 표시합니다. 주전 보유 선수는 `매각`, 미보유 선수는 `매입`을 표시합니다.

복귀는 기존 `BenchRestoreButton`을 재사용합니다. 아래 벤치 목록과 내 자산 화면에서 사용하는 검사·중복 클릭 억제·저장 표시·오류 알림·화면 갱신 흐름을 그대로 따릅니다. 실패나 정원 마감 때 버튼을 임의로 활성화하지 마세요.

연결은 `POST /api/kickx/squad/bench`이며 요청에는 `playerId`와 현재 `revision`을 보냅니다. 서버와 `kickx_restore_bench`가 최종 조건을 다시 검사합니다. 매입·매각 요청으로 대체하지 않습니다.

## 디자인 수정 시 유지할 것

- `app/styles/squad-market.css`의 `.squad-market-actions` 안에 복귀와 매각을 세로로 배치했습니다. 최대 너비는 기존 버튼과 같은 105px입니다.
- 선수 이름·구단·현재 가치와 버튼이 겹치지 않도록 이름 열의 `minmax(0, 1fr)`와 줄바꿈을 유지합니다.
- 복귀가 불가능한 경우 공통 버튼의 사유 안내를 읽을 수 있어야 합니다. 화면 폭 때문에 안내를 숨기지 마세요.
- 정상 복귀 후 오른쪽 행은 `보유` 상태와 매각 버튼으로 바뀌며, 경기장과 주전 인원도 갱신됩니다.
- 이 변경에는 DB 마이그레이션, 신규 폴링, 외부 축구 API 호출이 필요하지 않습니다.

## 확인 항목

`tests/roster-bench-browser.mjs`에서 320·390·768·1440px의 오른쪽 복귀·매각 표시, 복귀 요청, 경기장 인원 갱신, 포인트·원가 유지, 복귀 후 버튼 제거와 가로 넘침을 확인합니다. API 응답은 검증용 자료이며 운영 회원의 보유를 실제로 이동하는 검사가 아닙니다.
